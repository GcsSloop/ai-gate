# README Failover And Screenshot Design

## Goal

Update the Chinese and English product documentation so the README communicates two points more clearly:

- AI Gate can automatically fall back to another available account when the current account is exhausted or unavailable.
- The statistics page is part of the product surface and should appear in the screenshot section.

## Scope

- Update `README.md`.
- Update `docs/README.en.md`.
- Update `docs/README.zh-CN.md` so the redirect page mentions the new README content.

## Out Of Scope

- No product behavior changes.
- No screenshot asset changes.
- No backend or frontend code changes.
